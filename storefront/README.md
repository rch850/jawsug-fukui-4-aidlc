# FUKUI BASICS — EC サイト画面モックアップ

架空の自社アパレルブランド「FUKUI BASICS」の EC サイトを、**ローカルで操作できる画面モックアップ**として作ったものです。
商品一覧からカート、注文完了までの流れを確認できます。

> **これはデモです。** 決済・発送は行いません。カード番号などの入力欄はなく、支払い方法はダミーの選択肢だけです。
> サーバー・DB・外部 API は使いません。カートの中身はブラウザの localStorage に保存します（配送先などの個人情報は保存しません）。

## 起動方法

前提: Node.js 20.19 以上（Node.js 24 で動作確認済み）と npm。

```bash
cd storefront
npm install
npm run dev
```

表示された URL（通常は http://localhost:5173/ ）をブラウザで開きます。

## npm スクリプト

| コマンド               | 内容                                                                       |
| ---------------------- | -------------------------------------------------------------------------- |
| `npm run dev`          | 開発サーバーを起動する                                                     |
| `npm run build`        | 型チェック（`tsc -b`）と本番用ビルド（`dist/`）                            |
| `npm run preview`      | ビルド結果をローカルで表示する                                             |
| `npm run lint`         | ESLint と Prettier のチェック                                              |
| `npm run format`       | Prettier で整形する                                                        |
| `npm test`             | Vitest の単体テスト（`src/domain/*.test.ts`）                              |
| `npm run fetch-photos` | 商品写真を Unsplash から取り直す（通常は不要。写真は同梱済み。下記を参照） |

## 画面一覧

| パス            | 画面                                                                                       | ストーリー |
| --------------- | ------------------------------------------------------------------------------------------ | ---------- |
| `/`             | 商品一覧（カテゴリの絞り込み: すべて / メンズ / ウィメンズ / キッズ）                      | US-1、US-2 |
| `/products/:id` | 商品詳細（カラーとサイズを選んでカートに入れる。存在しない ID は「商品が見つかりません」） | US-3、US-4 |
| `/cart`         | カート（数量 1〜10 の変更、削除、合計金額）                                                | US-5、US-6 |
| `/checkout`     | 注文手続き（配送先の入力 → 確認の 2 段階。カートが空なら `/cart` へ）                      | US-7、US-8 |
| `/complete`     | 注文完了（ダミーの注文番号 `FB-YYYYMMDD-NNNN`。未確定なら `/` へ）                         | US-9       |

すべての画面に共通ヘッダー（ロゴで一覧へ、カートの件数は数量の合計）があります。

### 動作のポイント

- 同じ商品・カラー・サイズは 1 行にまとまり、1 行の上限は 10 個です。上限のときは「同じ商品は 10 点までです」と表示します。
- localStorage の値が壊れているときは、空のカートとして表示します（理由はブラウザのコンソールに警告として出ます）。
- 入力チェック: すべて必須。郵便番号は 7 桁、電話番号は 10〜11 桁（ハイフンと全角数字は無視して判定）、メールアドレスの形式。
- PC（1025px〜）は 4 列、タブレット（768〜1024px）は 3 列、スマートフォン（〜767px）は 2 列です。
- 操作できる要素には `data-testid` を付けています。

## 商品写真と出典

商品写真は [Unsplash](https://unsplash.com) の無料写真（Unsplash License。有料の Unsplash+ は使っていません）を 1 商品 1 枚、`public/images/` に同梱しています。
撮影者と写真ページは [`CREDITS.md`](./CREDITS.md) にあります。アプリは実行時にネットワークに接続しません。

`npm run fetch-photos`（`scripts/fetch-photos.mjs`）は、目視で選んだ写真 ID を取得し、取得できなければ検索語で代わりを探します。
このスクリプトは Unsplash の公式 API ではなく、ウェブサイトが内部で使う非公式のエンドポイントを API キーなしで呼んでいます。利用条件に沿っておらず、いつでも使えなくなりうるため、写真を取り直すときや本番で使うときは公式 API（Access Key は環境変数から読む）に切り替えてください。
写真を取得できなかった商品は `src/data/photos.json` に載らず、画面では 1 色目で塗った枠（商品名とカラー名入り）を表示します。
写真を差し替えたときは、`src/data/products.ts` の各商品の 1 色目を写真の服の色に合わせてください。

## ディレクトリ構成

```
storefront/
├── public/images/        商品写真（Unsplash、同梱）
├── scripts/fetch-photos.mjs  写真の取得スクリプト（開発時に一度だけ実行）
├── src/
│   ├── data/             商品 12 点、カラーコード、写真の出典（photos.json）
│   ├── domain/           画面に依存しない処理（絞り込み、カート、入力チェック、注文番号）とそのテスト
│   ├── state/            カートの状態（React Context + localStorage）
│   ├── components/       ヘッダー、商品カード、色見本、サイズ、通知、入力欄など
│   ├── pages/            5 画面
│   └── styles/           CSS 変数（tokens.css）と画面のスタイル（global.css）
└── CREDITS.md            写真の出典
```

## 技術

React 19、Vite、TypeScript（strict）、React Router、プレーンな CSS（CSS 変数）、Vitest、ESLint、Prettier。
